    O que é uma Árvore Binária?

    Uma árvore binária é uma estrutura de dados hierárquica em que cada elemento — chamado de nó — pode ter no máximo dois filhos: um à esquerda e um à direita. Diferente de um grafo geral, uma árvore não possui ciclos e sempre possui uma raiz única a partir da qual todos os demais nós são alcançados.

    A variante mais comum é a Árvore Binária de Busca (BST — Binary Search Tree), que segue uma regra fundamental de ordenação:

    Para qualquer nó N: todos os nós na subárvore esquerda têm valor menor que N, e todos os nós na subárvore direita têm valor maior que N.

    Essa propriedade torna as operações de busca, inserção e remoção muito eficientes, com complexidade O(log n) em árvores balanceadas.

    Terminologia

    Para trabalhar com árvores, é importante conhecer os termos utilizados:

    Raiz (Root) Nó do topo da árvore, sem pai. Ponto de entrada da estrutura.
    Nó (Node) Cada elemento da árvore, contendo um valor e ponteiros para filhos.
    Folha (Leaf) Nó que não possui filhos. Está no nível mais baixo da árvore.
    Filho (Child) Nó diretamente conectado abaixo de outro nó.
    Pai (Parent) Nó diretamente conectado acima de outro nó.
    Altura (Height) Número de arestas do caminho mais longo da raiz até uma folha.
    Nível (Level) Distância de um nó até a raiz. A raiz está no nível 0.
    Subárvore Qualquer nó junto com todos os seus descendentes forma uma subárvore.

    Tipos de Árvores Binárias

    Existem diferentes classificações de árvores binárias, cada uma com características específicas:

    🌳 BST (Binary Search Tree)

    Filhos esquerdo sempre menores e filhos direito sempre maiores que o nó pai. Facilita buscas eficientes.

    ⚖️ AVL

    BST autobalanceada: a diferença de altura entre subárvores esquerda e direita é sempre no máximo 1.

    🌿 Completa

    Todos os níveis estão completamente preenchidos, exceto possivelmente o último, preenchido da esquerda para a direita.

    🔵 Cheia (Full)

    Cada nó tem exatamente 0 ou 2 filhos — nunca apenas 1 filho.

    📏 Degenerada

    Cada nó tem apenas um filho, tornando a árvore similar a uma lista encadeada. Pior caso de uma BST.

    🔴⚫ Rubro-Negra

    BST balanceada com coloração de nós. Garante O(log n) mesmo em cenários adversos.

    Complexidade das Operações

    A eficiência das operações em uma BST depende diretamente do balanceamento da árvore. Em uma árvore balanceada, todas as operações são O(log n). No pior caso (árvore degenerada), chegam a O(n).

    Operação Caso Médio Pior Caso
    Busca O(log n) O(n)
    Inserção O(log n) O(n)
    Remoção O(log n) O(n)
    Travessia O(n) O(n)

    Diagrama de Nós

    A representação mais intuitiva é o diagrama em árvore, onde cada nó é desenhado com suas conexões para os filhos esquerdo e direito. A raiz fica no topo e as folhas na base. 

                50          ← raiz (nível 0)
           /  \
         30    70       ← nível 1
        / \   / \
       20  40 60  80    ← folhas (nível 2)

    Representação em Array

    Uma árvore binária completa pode ser armazenada em um array usando a seguinte convenção de índices:

    • A raiz fica no índice 1.
    • Para um nó no índice i, o filho esquerdo está em 2i e o direito em 2i + 1.
    • O pai de qualquer nó em índice i está em ⌊i / 2⌋.

    Para a BST do exemplo:

    0
    —
    1
    50
    2
    30
    3
    70
    4
    20
    5
    40
    6
    60
    7
    80

    O índice 0 é ignorado para simplificar os cálculos. Perceba: o filho esquerdo de 50 (índice 1) está em 2×1=2 → valor 30. ✓

    Representação em Código (Python)

    Em linguagens de programação, uma BST é geralmente implementada com uma classe Nó que contém o valor e ponteiros para os filhos:

    class No: def __init__(self, valor): self.valor = valor self.esquerda = None # filho esquerdo (menor) self.direita = None # filho direito (maior) class BST: def __init__(self): self.raiz = None def inserir(self, valor): if self.raiz is None: self.raiz = No(valor) else: self._inserir_rec(self.raiz, valor) def _inserir_rec(self, no, valor): if valor < no.valor: # vai para a esquerda if no.esquerda is None: no.esquerda = No(valor) else: self._inserir_rec(no.esquerda, valor) elif valor > no.valor: # vai para a direita if no.direita is None: no.direita = No(valor) else: self._inserir_rec(no.direita, valor)

    Travessias (Traversals)

    Uma travessia é o processo de visitar todos os nós de uma árvore em uma ordem específica. As três travessias clássicas diferem apenas em quando o nó atual é processado em relação aos seus filhos:

    🔵 In-Order (Esq → Nó → Dir)

    Visita esquerda, depois o nó, depois direita. Em uma BST, produz os valores em ordem crescente.

    Resultado: 20, 30, 40, 50, 60, 70, 80

    🟢 Pre-Order (Nó → Esq → Dir)

    Visita o nó primeiro, depois esquerda, depois direita. Útil para copiar ou serializar a árvore.

    Resultado: 50, 30, 20, 40, 70, 60, 80

    🟠 Post-Order (Esq → Dir → Nó)

    Visita os filhos antes do nó. Útil para deletar a árvore ou calcular expressões matemáticas.

    Resultado: 20, 40, 30, 60, 80, 70, 50

    # In-Order: percorre em ordem crescente def inorder(no): if no: inorder(no.esquerda) print(no.valor) inorder(no.direita) # Pre-Order: raiz → esquerda → direita def preorder(no): if no: print(no.valor) preorder(no.esquerda) preorder(no.direita) # Post-Order: esquerda → direita → raiz def postorder(no): if no: postorder(no.esquerda) postorder(no.direita) print(no.valor)
